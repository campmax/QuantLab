# Project summary

C++17 ETF backtester comparing trend, mean-reversion and buy-and-hold strategies with explicit accounting, execution costs and development/holdout separation.

## Résumé wording

Implemented a C++17 ETF backtester with trend and mean-reversion strategies, buy-and-hold benchmarks, next-open execution, transaction costs and separate development/holdout evaluation.

Describe this as a research project. Do not claim verified profitability or live production deployment. See the README and validation documentation for scope and limitations.
